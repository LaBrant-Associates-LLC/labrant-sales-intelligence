# LaBrant Sales Intelligence Handbook

SE Wisconsin Commercial Painting Market Intelligence

## Quick Start

Visit the live site: https://labrant-associates-llc.github.io/labrant-sales-intelligence/

## About

This repository contains the Sales Intelligence Handbook for LaBrant & Associates LLC, a commercial painting contractor in southeastern Wisconsin. The handbook consolidates market intelligence, GC relationships, pricing benchmarks, and sales execution guidance into a single searchable reference.

## Structure

- `docs/` - MkDocs source files
- `exports/` - Generated PDF/DOCX snapshots (labeled with date)
- `mkdocs.yml` - Site configuration
- `.github/workflows/` - Automated deployment
