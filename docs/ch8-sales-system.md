## Section 8.02 Bid Gate and Qualification

### Bid Gate Checklist

| Question | Pass | Fail | Action |
|----------|------|------|--------|
| Is GC merit-shop? | Yes | No/Unknown | Check Section 3.03, verify before proceeding |
| Is project in target tier? | Tier 1-2 | Tier 3 | Proceed with caution on Tier 3 |
| Is project in our geography? | Primary/Secondary | Tertiary+ | Consider travel costs |
| Does scope fit capacity? | $5K-$2M | Outside range | Evaluate crew availability |
| Is margin acceptable? | >25% target | <20% | Review pricing before bid |
| Is payment history good? | Known/verified | Problem history | Check Attachment A |

### Automatic Disqualification

| Factor | Action |
|--------|--------|
| GC on Avoid list (Section 3.03) | Do not bid |
| Public K-12 school construction | Do not bid |
| UW System project | Do not bid |
| Data center construction | Do not bid |
| Union PLA requirement | Do not bid |

## Section 8.03 Pipeline Management

### Pipeline Stages

| Stage | Definition | Action |
|-------|------------|--------|
| Identified | Opportunity known | Research GC, owner, timeline |
| Qualified | Passes Bid Gate | Add to active pursuit |

| Bidding | RFP received/in progress | Submit by deadline |

## Section 8.04 Capability Statements

### Capability Statement Template

**Page 1:**

- Company name and logo
- Certifications (prominent): SBE, DBE, LBE, Lead
- Contact information
- Brief company description (3-4 sentences)
- Key capabilities list

**Page 2:**

- Project experience (5-6 representative projects)
- Safety record (EMR, OSHA)
- Insurance summary
- References (2-3 with contact info)

### Certification Emphasis by Audience

| Audience | Lead With |
|----------|-----------|
| City of Milwaukee | SBE/LBE (25% + 10% preference) |
| Milwaukee County | DBE/TBE (25% goal) |
| WHEDA-funded | DBE |
| Private GC | Capacity, safety, experience |
| Religious/Schools | Lead certification, experience |
