# GC Prequalification Guide

## In 30 Seconds

Most merit-shop GCs require prequalification before bidding. Prepare a standard package that covers common requirements.

---

## Standard Prequalification Package

| Document | Status | Notes |
|----------|--------|-------|
| Capability Statement | Prepare | 1-2 pages, certifications prominent |
| Certificate of Insurance | Current | $2M GL, $1M umbrella, $1M auto |
| W-9 | Current | — |
| EMR (3 years) | Prepare | Request from insurance carrier |
| OSHA 300 Logs | Prepare | 3 years |
| Safety Manual | Current | — |
| Financial Statement (reviewed) | Prepare | May require CPA review |
| References (5 projects) | Prepare | Include contact info |
| Certification Copies | Current | SBE, DBE, Lead |

## Capability Statement Template

**Page 1:**

- Company name and logo
- Certifications (prominent): SBE, DBE, LBE, Lead
- Contact information
- Brief company description (3-4 sentences)
- Key capabilities list

**Page 2:**

- Project experience (5-6 representative projects)
- Safety record (EMR, OSHA)
- Insurance summary
- References (2-3 with contact info)
